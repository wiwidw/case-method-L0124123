## Isi Repositori
- `setm_bakery.py`: implementasi SETM (preprocessing, iterasi SETM, aturan asosiasi, analisis per segmen)
- `bread basket in london.csv`: dataset (sumber: Kaggle)
- `hasil_setm/`: keluaran program (itemset, aturan, grafik)
- `references/`: referensi

## Cara Menjalankan
1. Install library: `pip install -r requirements.txt`
2. Jalankan: `python setm_bakery.py`
3. Hasil tersimpan di folder `hasil_setm/`

## Parameter
Min support 1%, min confidence 30%
